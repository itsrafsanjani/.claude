Config Directory: `~/.claude/` 

Execute `chmod +x ~/.claude/statusline.sh`

The statusline uses emoji icons, so no special font is required — any terminal with emoji support will render it correctly.

The statusline needs `jq` 1.6+, `git` 2.11+ and bash 3.2+ (the bash that ships with macOS is fine). Install jq with `brew install jq` on macOS or `sudo apt install jq` on Debian/Ubuntu.
